# Recipe Page — Frontend Mentor Solution

A solution to the **Recipe page** challenge from [Frontend Mentor](https://www.frontendmentor.io). The page presents a clean, readable recipe card for a "Simple Omelette", including preparation time, ingredients, step-by-step instructions, and a nutrition table.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![Frontend Mentor](https://img.shields.io/badge/Frontend%20Mentor-Challenge-3e54a3)

## ✨ Features

- 🍳 Fully styled recipe card for a classic omelette
- ⏱️ Highlighted "Preparation time" callout box
- 🥗 Ingredients list with custom bullet styling
- 📋 Numbered step-by-step instructions
- 📊 Nutrition facts table (calories, carbs, protein, fat)
- 📱 Responsive design for desktop and mobile

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, flexbox, media queries

## 📂 Project Structure

```
├── index.html    # Main markup
├── style.css     # All styles
├── images/       # Omelette image, favicon, screenshots
├── design/       # Frontend Mentor design references
└── preview.jpg   # Challenge preview
```

## 🚀 Getting Started

No build step required:

```bash
git clone https://github.com/shena9y/Recipe-page-solution.git
cd Recipe-page-solution
start index.html   # or open it in any browser
```
